# Car Rental Project - Figma & Trello Board

This repository contains all the assets and information for the **Car Rental Project**. It includes both the design files from Figma and the project management details from Trello.

### Figma Design Files:
The Figma design files for the project are available in this repository. You can explore and download them for visual reference and to follow the design work.

### Trello Board Link:
The **Car Rental Board** on Trello tracks all tasks, progress, and activities related to the project.  
**Trello Board Link:** [Car Rental Board](https://trello.com/b/at9K2sJ2)

### Instructions:
- Download the Figma files to view the design assets.
- Access the Trello board for detailed project management and real-time updates.
- Explore the JSON file in the repository for a detailed export of the Trello board, which includes tasks, members, and activity logs.
